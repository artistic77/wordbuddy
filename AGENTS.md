# AGENTS.md

Guidelines and instructions for AI agents working in this repository.

## Overview

**Word Buddy** is a gamified English-Thai vocabulary learning web application featuring 10 Tamagotchi-style monster companions, RPG stats, boss arenas, sports arcade mini-games, and Azure AI speech/translation.

## Tech Stack & Commands

- **Framework**: React 18 + TypeScript + Vite + Tailwind CSS
- **State Management**: Zustand
- **Backend / Auth**: Supabase
- **Dev Server**: `npm run dev`
- **Build**: `npm run build`
