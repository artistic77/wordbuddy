## 🌟 ฟีเจอร์หลัก (Key Highlights)

### 🐾 10 Tamagotchi Monster Companions (สัตว์เลี้ยงคู่หู 10 แบบ)
คู่หูร่วมผจญภัยในรูปแบบการ์ตูน 2D Vector สีสันสดใส พร้อมระบบค่าพลัง RPG (STR, AGI, INT, BURST) และการดูแล (Hunger, Happiness, Level, EXP):
1. 🟢 **โมจิ (Moji)**: อ่อนโยน ขี้อาย — สไลม์ต้นอ่อนสีเขียวมินต์ 🌱
2. 🔵 **บับเบิ้ล (Bubble)**: สดใส ร่าเริง — หยดน้ำสีฟ้าสดใส ครีบดุ๊กดิ๊ก 💧
3. 🟡 **ปุยปุย (Pui Pui)**: ร่าเริง ขี้เล่น — ลูกเจี๊ยบไดโนเสาร์สีเหลืองพาสเทล 🐣
4. 🟣 **ลูโน่ (Luno)**: ลึกลับ เท่ๆ — มอนสเตอร์ปีศาจน้อยสีม่วง เขาสองข้าง หางหัวใจ 😈
5. 🌸 **มิลลี่ (Milly)**: น่ารัก อ่อนหวาน — กระต่ายหูตกสีชมพู ประดับดอกเดซี่ 🐰
6. 🐑 **ครีมมี่ (Creamy)**: ใจดี อบอุ่น — ลูกแกะขนปุยเมฆสีครีม เขาเกลียวทอง 🥐
7. 🦖 **กองก้า (Gonga)**: ซุกซน แข็งแรง — ไดโนเสาร์ตัวอ้วนสีเขียว หนามหลังสีเหลือง 🦖
8. ❄️ **วิงกี้ (Wingy)**: ขี้สงสัย ช่างฝัน — จิ้งจอกหิมะสีขาว ปีกนางฟ้าสีฟ้าใส 🪽
9. 🐈‍⬛ **ชาโดว์ (Shadow)**: สุขุม นิ่งๆ — แมวดำชาร์โคล อัญมณีเรืองแสงบนหน้าผาก 🔮
10. 🍊 **ซิตร้า (Citra)**: สดใส มองโลกในแง่บวก — ส้มสีส้มสดใส ลายเสี้ยวส้มบนหน้าท้อง 🍊

* **แว่นตา 20 แบบ**: แว่นกลม, แว่นกลมใส, แว่นดาว, แว่นพิกเซล Thug Life, แว่นหัวใจ, แว่นวินเทจ, แว่นเหลี่ยม, แว่นชัตเตอร์, แว่นโมโนเคิล, แว่นสปอร์ต, แว่นสตีมพังก์, แว่นสับปะรด, แว่นเลมอน ฯลฯ
* **ชุด 20 แบบ**: ชุดฮู้ดดี้, ชุดนักเรียนกะลาสี, ชุดไดโนเสาร์, ชุดแวมไพร์, ชุดเดรส, ชุดไหมพรม, ชุดนักกีฬา, ชุดพ่อมด, ชุดร็อคเกอร์, ชุดฮาวาย, ชุดนักสืบ, ชุดคุณหมอ, ชุดเชฟ, ชุดนักบินอวกาศ, ชุดกิโมโน, ชุดผึ้งน้อย, ชุดชาวไร่, ชุดทักซิโด้, ชุดนินจา, ชุดซานต้า
* **ระบบห้องแต่งตัว (Dress Up System)**: สวมใส่และถอดแว่นตา/ชุดได้แบบเรียลไทม์ พร้อมบวกค่าสเตตัสตัวละครทันที

### ⚔️ 5-Stage Adventure Boss Arena (สังเวียนศึกประลองบอส 5 ด่าน)
ดวลตอบคำถามคำศัพท์ภาษาอังกฤษ-ไทยแบบเทิร์นเบสกับบอสประจำด่าน:
1. 🌲 **Goblin Grunt** (ป่าพงไพรแห่งการเริ่มต้น)
2. ❄️ **Frost Yeti** (ยอดเขาหิมะเยือกแข็ง)
3. 🌋 **Magma Golem** (หุบเขาลาวาเดือด)
4. 🌌 **Shadow Wyrm** (วิหารเงาทมิฬ)
5. 👑 **Void Overlord** (บัลลังก์มิติว่างเปล่า)
* **ระบบต่อสู้**: มีหลอด HP บอส & ผู้เล่น, ป๊อปอัปดาเมจลอย, และ **🔥 ULTIMATE BURST (ดาเมจ x3)** เมื่อตอบถูกต่อเนื่อง 3 ข้อ!

### 🏀🎯⚽ 100% Pure Sports Arcade Suite (มินิเกมกีฬาแท้ 3 เกม)
มินิเกมกีฬาแอ็กชันประลองฝีมือและจังหวะแข่งกับบอท (เพิ่มค่า STR & AGI):
1. 🏀 **Arcade Basketball Shootout**: เกจวัดจังหวะเล็งเป้าซ้าย-ขวา กะจังหวะชู้ตให้ลงจุดกึ่งกลางสีเขียวเพื่อยิง 3 แต้มแบบ Swish!
2. 🎯 **Precision Target Darts**: เป้าเล็ง Crosshair เคลื่อนที่รอบกระดาน ปาลูกดอกให้เข้ากลางเป้า Bullseye 50 แต้ม
3. ⚽ **Penalty Soccer Showdown**: ดวลจุดโทษฟุตบอล เลือกทิศทางยิง 4 มุม (บนซ้าย, บนขวา, ล่างซ้าย, ล่างขวา) หลบผู้รักษาประตูสไลม์

### 📚 คลังคำศัพท์ Master Pool 1,050 คำ (Bilingual English-Thai)
* **ระดับง่าย (Easy)**: 350 คำ
* **ระดับปานกลาง (Medium)**: 350 คำ
* **ระดับยาก (Hard)**: 350 คำ
* ครอบคลุมคำแปลภาษาไทย, คำอ่านออกเสียงสัทศาสตร์ภาษาไทย (Phonetic Reading), ชนิดของคำ (Part of Speech), และเสียงพากย์มาตรฐานสากล

### 🤖 ระบบ AI & บริการเสริมอัจฉริยะ
* **Azure Cognitive Speech TTS**: เสียงอ่านคำศัพท์สำเนียงเจ้าของภาษาคมชัดเป็นธรรมชาติ
* **Azure Translator & Azure OpenAI (GPT-4o)**: วิเคราะห์คำศัพท์ แปลประโยคตัวอย่าง และช่วยจัดหมวดหมู่อัตโนมัติ
* **OCR Text Extraction**: ถ่ายภาพหรืออัปโหลดรูปภาพคำศัพท์เพื่อสแกนแปลงเป็นชุดคำศัพท์ได้ทันที

## 🚀 การติดตั้งและรันโปรเจกต์ (Getting Started)

### 1. โคลน Repository
```bash
git clone https://github.com/artistic77/wordbuddy.git
cd wordbuddy
```

### 2. ติดตั้ง Dependencies
```bash
npm install
```

### 3. ตั้งค่าตัวแปรสภาพแวดล้อม (Environment Variables)
คัดลอกไฟล์ `.env.example` ไปเป็น `.env`:
```bash
cp .env.example .env
```

กรอกข้อมูล API Keys ในไฟล์ `.env`:
```env
# Supabase
VITE_SUPABASE_URL=https://your-supabase-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key

# Azure AI & Speech
VITE_AZURE_SPEECH_KEY=your-azure-speech-key
VITE_AZURE_SPEECH_REGION=southeastasia
VITE_AZURE_TRANSLATOR_KEY=your-azure-translator-key
VITE_AZURE_TRANSLATOR_REGION=southeastasia

# Azure OpenAI (Optional)
VITE_AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/
VITE_AZURE_OPENAI_KEY=your-azure-openai-key
VITE_AZURE_OPENAI_DEPLOYMENT_NAME=gpt-4o
```

### 4. รันระบบสำหรับทดสอบ (Development Mode)
```bash
npm run dev
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:5173/`

### 5. บิลด์สำหรับ Production
```bash
npm run build
```
